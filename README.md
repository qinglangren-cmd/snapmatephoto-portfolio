# SnapMatePhoto — Content & Storytelling Case Study

A static portfolio website for GitHub Pages.

## Publish on GitHub Pages
1. Open your public `snapmatephoto` (or preferred) GitHub repository.
2. Upload `index.html` to the repository root.
3. Upload the entire `assets` folder, preserving the folder name and filenames.
4. In Settings → Pages, select Deploy from a branch, `main`, and `/(root)`.
5. Wait for deployment. The site will be available at the Pages URL shown by GitHub.

## Notes
- All page images are locally hosted in `assets/`; no image URLs are hotlinked.
- Photographer names/handles are generalized in the portfolio display.
- No performance uplift is claimed because historical analytics were not retained.
- The production guide button links to the Google Doc supplied by Lang.
